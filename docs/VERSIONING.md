# Правило версий

**Каждое исправление или изменение — новая версия.** Прежний номер повторно не выдаётся.

- Схема `MAJOR.MINOR.PATCH`. Исправления и мелкие изменения — PATCH +1 (0.0.5 → 0.0.6 → 0.0.7 …).
  MINOR и MAJOR повышаются только по прямой просьбе владельца проекта.
- Версия хранится в одном месте: `app.version` в `gradle.properties`. `versionCode` = major·10000 + minor·100 + patch
  и считается автоматически (0.0.5 → 5).

## Чек-лист при каждой выдаче новой сборки или архива
1. Поднять `app.version` в `gradle.properties`.
2. Добавить раздел новой версии в начало `CHANGELOG.md`.
3. Обновить строку «Версия …» в `README.md`.
4. Не менять `applicationId` и ключ из `signing/`.
