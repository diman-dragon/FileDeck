# Тесты нативной части

81 проверка логики плагинов на настольной JVM: сканер (дубликаты, похожие фото, пустые папки,
мусор, исключения, Android/data), корзина (перенос, восстановление с конфликтом имён, очистка, срок хранения),
архиватор (ZIP / 7z / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ, пароли, выборочная распаковка, Zip Slip, битые архивы).

Заглушки `stubs/` повторяют публичные сигнатуры Capacitor, `fakes/` — те части Android API, которыми
пользуется код (Environment, BitmapFactory на ImageIO и т. д.). Запуск: `npm run test:native` (Linux/macOS, см. run.sh).
