# Журнал изменений

Версия берётся из `app.version` в `gradle.properties`. versionCode Android = major·10000 + minor·100 + patch.

## 0.0.6 — 2026-10-24
**Атомарность интерфейса и финальная проверка**
- Общие компоненты: `ItemRow` (строка списка — файлы, очистка, корзина, архив) и `Pill` (хлебные крошки) вместо четырёх
  и двух копий разметки; `hasAccess()` без дублирующей обёртки; ошибки очистки корзины пишутся в лог.
- Дубликаты строк объединены (19), ключ SD-карты — `storage_sd`; сборочный дистрибутив Gradle — `-bin`.
- Проверено по всему репозиторию: ни Capacitor, ни Cordova, ни WebView, ни npm/Node, ни веб-ресурсов не осталось;
  баланс скобок, импорты и ссылки на ресурсы сверены скриптами.

## 0.0.5 — 2026-10-24
**Чистка: совместимость со старым не нужна**
- Минимальная версия Android — 11 (API 30): удалены запрос доступа для Android 10 и ниже, разрешения `READ/WRITE_EXTERNAL_STORAGE`,
  ветвления по `SDK_INT`, лишний запрос `requestLegacyPermission`.
- Удалены: `proguard-rules.pro` (R8 выключен), `cache-path` из `file_paths.xml`, дубликат и исходник логотипа в `branding/`,
  `-v26` в имени папки иконок, упоминания прежней версии в документах и журнале, правила отступов `.editorconfig` для JS.

## 0.0.4 — 2026-10-24
**Исправления по аудиту** (релизный ключ и безопасность — без изменений, сборка «для себя»)
- Права: проверка при каждом возврате в приложение (отзыв доступа замечается), убран двойной запуск проверки при старте.
- Текущая папка обновляется при возврате из других приложений; выделение очищается от исчезнувших файлов; корзина
  перечитывается только на главном экране.
- Поиск не заходит в `.FileDeckTrash`, прерывается при новом запросе, у папок в результатах считается число элементов.
- Очистка: вложенные пути не удаляются дважды (быстрая очистка и «удалить выбранное»).
- Открытие APK: добавлено разрешение `REQUEST_INSTALL_PACKAGES`; убран бесполезный `requestLegacyExternalStorage`.
- Смена языка пересоздаёт интерфейс (убраны `locale` и `layoutDirection` из `configChanges`).
- Строки: тексты ядра (ошибки, типы файлов, категории очистки, единицы, месяцы), склонения (`plurals.xml`) и составные
  сообщения вынесены в ресурсы; самописный `plural()` удалён; составные подписи собираются через `meta()`.
- Ядро: `FileOpener` и `MimeTypes` переписаны на Kotlin; RAR распаковывается прямым вызовом junrar (без рефлексии); флаги
  отмены и занятости — `AtomicBoolean`; убраны все `!!`; `FileEntry.mime` считается лениво.
- Структура: `Cleaner.kt` → `CleanerService`/`DuplicateFinder`/`SimilarImageFinder`/`CleanerLogic`; `Components.kt` → `Theme`/`Icons`/
  `Widgets`/`Dialogs`; `Screens.kt` → шесть файлов экранов. Удалены неиспользуемые импорты и полные имена в коде.
- Комментарии: убраны баннеры, пересказывающие KDoc и шумовые строки; остались пояснения «почему».
- Сборка: каталог версий `gradle/libs.versions.toml`, шаг Lint в CI, `lint` не блокирует сборку.
- Тесты: `TrashServiceTest` (круг «в корзину → список → восстановить», конфликт имён, очистка), `DeepScannerTest`
  (дубликаты, мусор, пустые папки и файлы, вложенное пустое дерево).

## 0.0.3 — 2026-10-24
**Рефакторинг по результатам аудита (поведение не меняется)**
- Строки интерфейса вынесены в `res/values/strings.xml` (≈250 строк, доступ через `Str.s/Str.f` в местах без Context). Несколько
  составных сообщений с вложенной логикой пока остаются в коде.
- `AppViewModel` разделён: диалоги, прогресс и уведомления → `UiHost` (интерфейс `UiHostApi`, делегирование), действия над
  файлами и буфером → `FileActions.kt`; остались навигация и состояние (787 → ~470 строк).
- Контроллеры разнесены по файлам: `ArchiveFlows`, `ArchiveBrowser`, `TrashController`, `EditorController`, `CleanerController`.
- Очистка: выбор «в корзину / навсегда» через `suspend choose()` вместо опроса диалога таймером.
- Единая таблица расширений (`Format.kt`): `FileKinds.java` удалён, правила мусора — в `FileRules.kt`. `FsUtil` переписан на Kotlin.
  Мелкие изменения категорий очистки: .heif, .wmv, .mid, .iso, .apks/.apkm, .djvu учитываются так же, как в интерфейсе; `.ts` — код.
- Удалён мёртвый код (`Icons2.restore`, `ArchiveService.isBusy`), лишние растровые иконки `mipmap-*` (minSdk 26 → адаптивные), пустой `drawable/`.
- Тема: убраны устаревшие `statusBarColor`/`navigationBarColor`; включён `enableOnBackInvokedCallback` (предиктивный «Назад»).
- Проигнорированные ошибки пишутся в Logcat (`Log.w`).
- Тесты: `CleanerLogicTest` (выбор копий, `purge`, вложенные пути, таблица расширений, правила мусора, сортировка).

## 0.0.2 — 2026-10-24
**Исправления**
- Приложение закрывалось сразу после заставки: в манифесте стартовый экран был указан как `.MainActivity`, а класс лежит в

- Экран аварии: при падении показывает текст ошибки с кнопками «Копировать» и «Поделиться».
- Защита от падения при запросе фокуса в поле поиска и в диалогах ввода.
- GitHub Actions: убран падавший шаг `setup-android`, добавлены принятие лицензий SDK и `chmod +x gradlew`.

## 0.0.1 — 2026-10-24
**Первая версия: нативный Android (Kotlin + Jetpack Compose)**
- Нативный интерфейс на Jetpack Compose + Material 3.
- Все возможности сохранены: накопители и быстрый доступ, список и сетка с миниатюрами, поиск, выделение, копирование /
  перенос / удаление, переименование, свойства, просмотр изображений (свайп, зум), текстовый редактор, глубокая очистка,
  корзина с восстановлением, настройки с тремя вкладками, темы «Тёмная» / «Светлая» / «Как в системе».
- **Архивы**: создание ZIP (AES-256 с паролем), 7z, TAR, TAR.GZ/BZ2/XZ; просмотр содержимого и выборочная распаковка
  ZIP / 7z / TAR* / GZ / BZ2 / XZ; распаковка RAR (v4); защита от Zip Slip, прогресс и отмена. Движок форматов без изменений.
- Нативное ядро (файлы, архивы, очистка, корзина) переписано на Kotlin без JSON-моста; чтение и запись форматов — прежние,
  проверенные Java-классы.
- **Сборка в GitHub Actions**: тесты, debug/release APK и AAB как артефакты; по тегу `v*` — релиз с файлами.
- Модульные тесты на JVM (`./gradlew testDebugUnitTest`): круговой обмен всеми форматами архивов, пароль, Zip Slip,
  защита от перезаписи при копировании, форматирование, выбор «что оставить» при очистке.
