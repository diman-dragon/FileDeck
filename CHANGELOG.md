# Журнал изменений

Версия берётся из `app.version` в `gradle.properties`. versionCode Android = major·10000 + minor·100 + patch.

## 0.0.2 — 2026-10-24
**Исправления**
- Приложение закрывалось сразу после заставки: в манифесте стартовый экран был указан как `.MainActivity`, а класс лежит в
  пакете `ui` → теперь `.ui.MainActivity`.
- Экран аварии: при падении показывает текст ошибки с кнопками «Копировать» и «Поделиться».
- Защита от падения при запросе фокуса в поле поиска и в диалогах ввода.
- GitHub Actions: убран падавший шаг `setup-android`, добавлены принятие лицензий SDK и `chmod +x gradlew`.

## 0.0.1 — 2026-10-24
**Полный переход на нативный Android (Kotlin + Jetpack Compose)**
- Интерфейс переписан с HTML/CSS/JS (Capacitor) на Jetpack Compose + Material 3. WebView, Node.js и Capacitor больше не нужны.
- Все возможности сохранены: накопители и быстрый доступ, список и сетка с миниатюрами, поиск, выделение, копирование /
  перенос / удаление, переименование, свойства, просмотр изображений (свайп, зум), текстовый редактор, глубокая очистка,
  корзина с восстановлением, настройки с тремя вкладками, темы «Тёмная» / «Светлая» / «Как в системе».
- **Архивы**: создание ZIP (AES-256 с паролем), 7z, TAR, TAR.GZ/BZ2/XZ; просмотр содержимого и выборочная распаковка
  ZIP / 7z / TAR* / GZ / BZ2 / XZ; распаковка RAR (v4); защита от Zip Slip, прогресс и отмена. Движок форматов без изменений.
- Нативное ядро (файлы, архивы, очистка, корзина) переписано на Kotlin без JSON-моста; чтение и запись форматов — прежние,
  проверенные Java-классы.
- **Сборка в GitHub Actions**: тесты, debug/release APK и AAB как артефакты; по тегу `v*` — релиз с файлами.
- Тот же `applicationId` и ключ подписи, что у прежней Capacitor-версии.
- Модульные тесты на JVM (`./gradlew testDebugUnitTest`): круговой обмен всеми форматами архивов, пароль, Zip Slip,
  защита от перезаписи при копировании, форматирование, выбор «что оставить» при очистке.
