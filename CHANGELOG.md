# Журнал изменений

Версия берётся из `package.json` (`npm run bump`). versionCode Android = major·10000 + minor·100 + patch.

## 2.0.4 — 2026-10-14
**Навигация**
- Системная кнопка «Назад» возвращает на шаг назад по истории переходов (папки, переключение «Память / SD-карта»,
  главный экран) до стартового экрана и там остаётся: приложение больше не закрывается по «Назад».
  Сначала по-прежнему закрываются окна и листы, затем снимается выделение и закрывается поиск.
- Стартовый экран определяется настройкой «При запуске открывать».

## 2.0.3 — 2026-10-14
**Корзина**
- Восстановление, удаление и очистка показывают окно с полосой прогресса, именем текущего файла и кнопкой «Отмена».
  Прогресс считается по байтам, поэтому большая папка двигает полосу плавно.
- Новый вызов `trashCancel` и событие `trashProgress` в нативном плагине очистки.

**Настройки**
- Темы называются «Тёмная» и «Светлая» (были «AMOLED» и «Светло-коричневая»).

**Сетка файлов**
- Колонки сетки фиксированной ширины (`minmax(0, 1fr)`): длинные имена и крупные иконки больше не раздвигают сетку за край экрана.
- Класс строки под панелью переименован в `.subbar`: раньше он случайно добавлял отступы подписям файлов.

## 2.0.2 — 2026-10-14
**Корзина**
- Очистка и удаление из корзины показывают «Очищаем корзину…» на время операции и блокируют повторные нажатия.
- Если часть файлов удалить не удалось, приложение говорит об этом («Удалено: N, не удалось: M»), а не сообщает об успехе.

## 2.0.1 — 2026-10-14
**Настройки**
- Экран настроек разделён на подэкраны: «Внешний вид», «Файлы», «Корзина и очистка», «При запуске открывать»,
  «Доступ к файлам», «О приложении». Главный экран настроек — список разделов с текущими значениями.
- Убраны блоки «Установленная сборка» и «Подпись приложения (SHA-256)».
- Код настроек разложен по файлам в `src/settings/` (по одному разделу на файл).

## 2.0.0 — 2026-10-10
**Глубокая очистка**
- Один проход по памяти и SD-карте: дубликаты (по содержимому, а не по имени), похожие фото (перцептивный хеш),
  мусор и кэш, установщики APK, пустые папки, пустые файлы, самые большие файлы, раскладка занятого места по типам.
- Для каждой группы дубликатов приложение само выбирает, какой экземпляр оставить; выбор можно изменить.
  «Быстрая очистка» убирает только безопасное. Папки приложений (Android/data) не затрагиваются.
- Предпросмотр файла и переход в папку прямо из результатов; прогресс и отмена сканирования.

**Корзина**
- Удаление по умолчанию отправляет файлы в корзину с восстановлением (7 / 30 / 90 дней, настраивается).
  Автоматическая очистка просроченного, «Удалить навсегда» остаётся отдельным действием.

**Архиватор**
- Создание: ZIP (с паролем AES-256), 7z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ; уровень сжатия; прогресс и отмена.
- Распаковка и просмотр содержимого: ZIP, 7z, TAR*, одиночные GZ/BZ2/XZ, RAR 4; пароли (с повтором при ошибке),
  выборочная распаковка, режимы «в папку» и «сюда». Защита от Zip Slip, откат при ошибках.

**Подпись и обновления**
- Один и тот же ключ подписи для всех debug/CI/sideload-сборок; сборка останавливается, если ключа нет.
- Перед сборкой печатается отпечаток ключа; `npm run doctor` сравнивает подпись с установленным на телефоне
  приложением и говорит, обновится ли оно поверх; `npm run keygen` создаёт личный ключ для магазина.
- В «Настройки → О приложении» видны версия, versionCode, даты установки и отпечаток подписи.

**Прочее**
- Иконка в стиле DataLaw: тёмно-синий фон, кремовая D, значок с папкой.
- Минимальная версия Android — 8.0 (API 26). Нативная логика покрыта 81 автоматической проверкой (`npm run test:native`).

## 1.0.1 — 2026-07-10
- Логотип DataLaw: иконка приложения (папка с буквой D), заставка, шапка и экран «О приложении».
- Настройки в виде шестерёнки: тема, вид списка, сортировка, скрытые файлы, подтверждение удаления,
  стартовый экран, статус доступа к файлам, сброс.
- В шапке всегда доступны кнопки «Память» и «SD-карта» — в том числе при ошибках и пустых папках.
  Повторное нажатие на активный накопитель возвращает в его корень.
- Темы: AMOLED (чистый чёрный) и светло-коричневая.
- Обновление поверх установленной версии: общий ключ подписи в репозитории + автоматический versionCode.
- Подготовка к публикации: сборка AAB, раздел подписи для Google Play, документы в `docs/`.
- Исправлен запуск Gradle на системах, где у `gradlew` нет бита исполняемости.
